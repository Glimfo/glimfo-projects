Wrapper repository strategy keeps customizations separate from Redmine core. Upgrade by changing one line in the Dockerfile.

Quick Start

Get Glimfo Projects running in under 5 minutes.

# Clone the repository
$ git clone https://github.com/Glimfo/glimfo-projects.git
$ cd glimfo-projects

# Configure environment
$ cp .env.example .env
$ nano .env

# Launch
$ docker compose up -d
