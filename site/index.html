Features

Everything you need to manage projects

Built on Redmine's battle-tested core with Glimfo-branded customizations, modern security, and enterprise-grade infrastructure.

🔗

GitHub Integration

Link repositories, auto-reference commits in issues, get webhook-driven updates, and connect pull requests to your project workflow.

🐳

Docker Compose Stack

One-command deployment with PostgreSQL, Redis, Nginx with auto-SSL via Let's Encrypt. Production-ready out of the box.

🔒

Enterprise Security

HTTPS only, HSTS, rate limiting, CSRF protection, secure cookies, Trivy vulnerability scanning, and Docker hardening built-in.

🔑

OAuth Authentication

Sign in with Google or GitHub accounts. Optional LDAP integration and two-factor authentication support for maximum flexibility.

🚀

CI/CD Pipelines

GitHub Actions for build, test, Dockerfile linting, security scanning, container image publishing, and automated deployments.

🔄

Painless Upgrades

Wrapper repository strategy keeps customizations isolated in themes and plugins. Merge upstream Redmine releases with minimal conflicts.
